# منصة د. مرفت سرور

- `design/index.html` التصميم الحالي للصفحة الرئيسية (افتحه في المتصفح). `home-v1.html` و`home-v2.html` نسخ سابقة للمقارنة.
- `design/assets/art/` الصور الفنية لكل تمرين وكورس (تُولَّد بالسكربت `tools/make_art.py`).
- `brand/` الشعار بخلفية شفافة ونسخه وأيقونات المتصفح.
- `docs/plan.md` خطة الموقع: خريطة الصفحات، WordPress، بوابات الدفع، التسعير حسب الدولة، SEO.
