# منصة د. مرفت سرور

## النموذج الكامل (site/)
`site/` موقع كامل قابل للتصفح (٣٤ صفحة): الرئيسية، استيقظ VIP، مكتبة التمارين، صفحة لكل تمرين، كورس عين صاحية، الكتب، قارئ الكتاب، الجلسات والحجز، عن د. مرفت، الأسئلة الشائعة، تواصل، دخول/حساب جديد، لوحة الحساب، مشغّل الدروس، السلة، الدفع، نجاح/فشل الدفع، والصفحات القانونية، مع sitemap.xml وrobots.txt.

لتشغيله محلياً:
```bash
cd site && python3 -m http.server 8000
```

السلة والدفع والحساب في النموذج تجريبية (تُحفظ في المتصفح). في الإطلاق الفعلي تُستبدل بـ WordPress + WooCommerce + Tutor LMS وبوابات الدفع (انظر `docs/plan.md`).

## التعديل
- المحتوى (المنتجات، الأسعار، الدروس، الأسئلة الشائعة، السياسات) كله في `tools/build_site.py`، ثم:
```bash
python3 tools/build_site.py
```
- التصميم: `src/assets/css/site.css` — السلوك: `src/assets/js/site.js`.
- الصور الفنية: `tools/make_art.py` — صور المدربة على خلفيات الهوية: `tools/make_portraits.py` (الصور المقصوصة في `brand/photos/`).
- الدومين المؤقت في `SITE_URL` داخل `tools/build_site.py` يُستبدل بالدومين الحقيقي.

## مجلدات أخرى
- `brand/` الشعار بخلفية شفافة ونسخه وأيقونات المتصفح وصور المدربة.
- `design/` نماذج التصميم السابقة للمقارنة.
- `docs/plan.md` الخطة: بوابات الدفع، التسعير حسب الدولة، SEO.
