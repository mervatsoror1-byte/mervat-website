# أين وصلنا (آخر تحديث)

## تم
- الموقع ٣٦ صفحة بالهوية الجديدة (أزرق ملكي، ذهبي مطفي، كريمي) وخطوط صفية.
- الشراء المباشر، اشتراكاتي، علامة العين، السياسات الأربع ببنود صفية.
- برنامج استيقظ VIP = جلسات فردية خاصة (ليس جماعياً) — مصحح في كل الموقع.
- **صور الصفحة الرئيسية الشخصية كلها جاهزة:** الواجهة، شريط «أنا مرفت» (صورتان)، من هي مرفت، بانر بوابة الشفاء، بطاقة الجسر، بانر الجلسات وبطاقتها، الشروق، النافذة المنبثقة.
- أداة الصور المعتمدة: ChatGPT داخل مشروع «صور موقع مرفت» (انظر docs/visual-identity.md).

## التالي
1. أغلفة الأدوات (فارغة بانتظار تصميم مرفت).
2. آراء المشتركين (حقيقية).
3. صفحة «عن مرفت» على شكل صفحة صفية + صورها.
4. باقي الصفحات: الاستشارات، صفحة VIP، السلة، الدفع.
5. السلايدر (آراء المشتركين) عند الوصول لصفحته.

## ٤ نوفمبر ٢٠٢٦
- صفحة استيقظ VIP: صورة جلسة Zoom الجديدة (vip-zoom.webp) بدل صورة الأخضر، ونجوم ذهبية أكثر في الصدارة.
- اشتراكات VIP: شهري 2999/149$ · ٣ أشهر 7999/399$ · سنوي 29999/1499$.
- تسعير نفسي لكل المنتجات (ينتهي بـ٩).
- زر «جنيه مصري / دولار $» في الفوتر لمعاينة الأسعار بأي عملة.

## ٥ نوفمبر ٢٠٢٦
- أسعار الجلسات: تعارف ٣٠ دقيقة 399/25$ · ٦٠ دقيقة 599/59$ · باقة ٤ جلسات 1999/149$.
- صفحات الدخول والتسجيل: صورة مرفت واقفة باللابتوب (auth-standing.webp) تملأ النصف، اقتباس واحد بإطار ذهبي.
- السلة وإتمام الشراء: رأس أزرق ملكي بالنجوم، وجسم عاجي بخطوط ذهبية — بلا ألوان الموقع القديم.

## ٥ نوفمبر ٢٠٢٦ (٢)
- الرئيسية: حذف شريط «أنا مرفت» بالصورتين، وحذف جملة «كل أداة تُشترى منفصلة…»، و«من هي مرفت» على أزرق ملكي بنص جديد وأرقام (٨ سنوات · +٥٠٠ ساعة · +١٠٠ متدرب).
- الألوان القديمة (البنفسجي/اللافندر) استُبدلت بالأزرق الملكي في كل الموقع، والقائمة العلوية أسمك.
- عين صاحية لم تعد ضمن استيقظ VIP (VIP = الجلسات + كل التمارين). الخطة اليومية «يوماً بيوم».
- «كوتش وعي» ← «مدربة وعي»، و«الاتحاد الدولي للكوتشينج» ← «للتدريب».
