# أغلفة التمارين والكورسات — القالب الموحد

كل غلاف = **الأساس الثابت** (لا يتغير) + **رمز التمرين** (يتغير لكل تمرين).
لا نكتب أي نص داخل الصورة: اسم التمرين يكتبه الموقع فوق البطاقة.
المقاس 16:9 (يصلح لبطاقة الموقع ولصورة الفيديو على Bunny معاً).

## الأساس الثابت (يُنسخ كما هو في كل برومبت)
```
لوحة فنية رمزية فاخرة بأسلوب واحد ثابت لسلسلة أغلفة: خلفية سماء ليلية بالأزرق الملكي العميق (#1F3F7C إلى #3A62A8) مع نجوم ذهبية صغيرة متناثرة ووهج نور ذهبي ناعم في المنتصف. إطار قوسي رفيع بلون الذهب المطفي (#C5A059) يحيط بالعنصر الرئيسي في المنتصف. لمسات من الكريمي (#F5F5DC). إضاءة دافئة حالمة وهادئة، تفاصيل دقيقة، بدون أي أشخاص، بدون أي نص أو حروف أو شعارات. العنصر الرئيسي في المنتصف مع مساحة هادئة حوله. مقاس عرضي 16:9.
```
